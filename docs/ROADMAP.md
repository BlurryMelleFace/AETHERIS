# AETHERIS — Roadmap

## M0: Bootstrap
- [x] Repository scaffold, project, sample scene and player
- [x] Basic editable terrain prototype
- [ ] Verify build in installed Godot editor

## M1: Living Forest (vertical slice)
- [ ] Replace node-per-block terrain with data-driven chunks
- [ ] Seed-based terrain generation and simple caves
- [ ] Responsive movement and basic interactions
- [ ] Mine/place interaction limits and inventory
- [ ] Layered art, dynamic lights, fog and day/night cycle
- [ ] World saves and deterministic reload
- [ ] First enemy, resource and crafting recipe

## M2: Caverns and Progression
- [ ] Cave biomes, ores and generation rules
- [ ] Equipment and combat system
- [ ] First dungeon, boss and progression unlock

## M3: Surface water / Ocean
- [ ] Swimming, oxygen, boats, aquatic ecosystems
- [ ] Underwater cave or ruin and pressure system

## M4: Planetary Expedition
- [ ] Independent world seeds, universe map, planet travel
- [ ] New gravity and atmosphere parameters
- [ ] Customizable spacecraft prototype

## M5: Multiplayer (later)
- [ ] Authority, interest management, persistence and replication

Never expand the scope before validating the preceding milestone.
